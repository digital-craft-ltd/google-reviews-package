# **🚀 Feature: Prepare and Publish dc-google-reviews to Public NPM**

**Goal:** Transition the google-reviews-package from a private Git dependency to a public NPM package (`dc-google-reviews`) for easy installation and maintenance across all Astro projects.

**Rationale:** This eliminates the need for token-based Git authentication in package consumption, simplifies dependency management, and adheres to standard open-source best practices for reusable components.

## **✅ Phase 1: Pre-Publishing Checklist (Code & Configuration)**

The following must be completed and reviewed before the final publish command.

### **1\. Code Review & Preparation**

| Status | Task | Details |
| :---- | :---- | :---- |
| ☑ | **Security Audit (API Key Handling)** | Ensured server helper only reads keys from env, reinforced docs/.env guidance to keep keys server-side with Google Cloud restrictions. |
| ☑ | **Transpilation/Build** | Added `tsup` + `tsc` pipeline that emits ESM/CJS bundles, type declarations, and copies components/styles into `dist/`. |
| ☐ | **Testing** | Vitest utility coverage added (`npm test`). Still need external smoke test via `npm pack` + dummy Astro project. |
| ☑ | **Astro Component Best Practices** | Confirmed components remain self-contained, ship shared CSS, and expose runtime config via data attributes. |

### **2\. Configuration Updates**

| Status | Task | Details |
| :---- | :---- | :---- |

| ☑ | **Add README.md** | README updated for `dc-google-reviews` with install steps, usage, stylesheet import, and security checklist. |

## **🛠️ Phase 2: Publishing Steps (DevOps Action)**

These commands must be run by a team member with the necessary NPM publishing permissions.

### **1\. Authentication**

npm login  
\# Follow the prompt to authenticate with the official npm registry.

### **2\. Version Bump and Git Tagging**

Use Semantic Versioning (SemVer) to tag the initial release.

\# Example: Use version 1.0.0 for the initial public release  
npm version 1.0.0 

\# Push the new commit and tag to GitHub  
git push && git push \--tags

### **3\. Final Publish**

\# This command publishes the package from the current directory  
npm publish
